GitHub connection

Publishing needs a GitHub token. Make it once:

  1. On github.com open Settings, Developer settings, Personal access tokens, Fine-grained tokens.
  2. Generate new token. Repository access: only your site repository.
  3. Permissions: Contents, Read and write. Pick the longest expiry.
  4. Copy the token and paste it below.
Saved only on this phone. It is never put in the site files.

Online saves

Players create a username and password, and their game progress is saved online with Firebase. Do the Firebase setup, then paste its config here.

Database rules

In Firebase open Firestore Database, Rules. Replace everything with this text and press Publish. It lets each player reach only their own saves, and lets anyone send a problem report. Reports can only be read by you, in the Firebase console under Firestore Database, Data, reports.
